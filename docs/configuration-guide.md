# 配置与输入说明

本包包含 75 组表 III 基线配置及 N1 的 54 组角度配置。配置记录包含原生输入、参数和运行信息。

[配置清单](../manifests/configurations.json) 是参数与输入文件的唯一完整索引；[算例映射](../manifests/case_map.csv) 解释论文名称与历史目录名称的差别。`cases/` 下提供按算例浏览的文件链接。

## 使用配置

1. 根据评分清单中的 `config_id` 找到配置记录。
2. `parameters` 给出网格、谱阶、边界、模态和输出设置。原生输入文件是完整环境剖面和实际运行参数的依据。
3. 将 `files` 中 `role` 为 `native_input`、`starter` 或 `auxiliary_input` 的对象复制到新工作目录，并使用 `work_name` 命名。另列的 `starter_sources` 记录起始场生成来源。
4. `native_commands` 来自历史运行记录，记录程序变体、参数和线程设置。其中的源路径相对于原项目；运行时将程序和路径替换为本机位置，输入文件使用 `work_name` 指定的名称。

输入按 SHA-256 内容去重。相同字节只保存一次；不同配置通过文件映射复用。FOR3D 的共享 `e_ln3_f.spd` 辅助表和 RAM 自由场的 `water_atten_profile.dat` 已按实际文件收录。

## 参数说明

- SSP 的 RAM 原生距离在部分外部起始场计算中采用平移后的推进坐标；与论文的绝对距离通过起始距离对应。
- CT-S 的 `orders` 是各层多项式阶数 N；系数数目为 N+1。`output_dz_m` 表示输出深度采样。外部起始场文件是实际注入状态。
- SSF 的正深度域和镜像网格共同组成 FFT 域；C1 的局部深度偏移、滤波及平滑参数均保留。
- WAMPE 的实际模态数与 `max_mode` 上限分别记录。PML 同时给出网格数与物理厚度；环境和地形数组内嵌于原生 JSON。
- C9 的 LSS-FD 基线为 0.04°。`Nx2D` 为目录和 ID 中对论文 N×2D 的 ASCII 写法。
- N1 为 3 个频率、6 个角度及 3 种方法。截断角和实际模态编号随每个配置保存。
- 起始场来源按实际归档记录保留。C1 的运行记录指向 Green 函数起始场分支；C3 指向 COMSOL 共轭转换分支。
- 各方法的准确评价坐标、参考场和评分规则由评分数据清单提供。
